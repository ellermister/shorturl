# 常见问题

### 1. 和普通短链有什么不同？

常见短链主要是把长网址变短，方便传播和排版。

ShortURL 更侧重「可控地分享」：你可以限制谁能打开、用什么设备或地区打开、打开几次、是否需要密码，并可选加密跳转，让真实目标不那么容易被直接抓取或批量探测。适合把链接交给指定客户或同事，而不是公开扔到不可控的转发链路里。

### 2. 「禁止国产端」是什么意思？

指拦截微信、QQ、部分国产浏览器及其 App 内置浏览器（WebView）等常见环境。

这些环境里访问记录更容易被平台侧采集或预览。开启后，来自这类客户端的访问会被拒绝（按你的设置进入伪装站或显示无效），从而降低链接在不可控 App 内被打开、预览的风险。

### 3. 什么是「伪装」？

开启伪装后，当访问不满足限制条件（如设备、地区、浏览器环境不符，或校验失败）时，不会把真实目标暴露给对方，而是跳转到一个无关的伪装页面。

满足条件的正常访问仍会按你的设置跳转到真实网址。

### 4. 什么是「阅后即焚」？

短链在成功跳转一次后即失效，之后再打开将无法访问真实目标。

适合一次性交接、临时凭证或希望链接不要长期留在网上的场景。未成功跳转（例如输错密码）一般不会消耗这次机会。

### 5. 什么是「密码保护」？

打开短链时需要先输入密码，通过后才能继续跳转。密码可自定义，也可由系统自动生成。

### 6. 什么是「仅电脑 / 仅手机」？

限制只有电脑端或只有手机端可以成功跳转；另一类设备会被拒绝访问。

适合内容本身只适配某一端，或你希望接收方必须在指定设备上打开的场景。

### 7. 什么是「仅大陆 / 仅海外」？

按访问者 IP 归属限制地区：

- **仅大陆**：主要允许中国大陆 IP
- **仅海外**：主要允许非中国大陆 IP

不满足地区条件的访问会被拒绝。适合活动、资源或需要按地区投放的场景。

### 8. 什么是「无来源」？

这个功能主要面向「把短链接放在自己网站上分享」的场景。

举例：你在 A 站放了一个短链接，访客点开后最终会跳到 C 站。正常情况下，C 站有时能通过浏览器的来源信息（Referer）知道用户是从 A 站过来的。

开启「无来源」后，出站时尽量不向 C 站发送来源信息，避免 C 站据此发现流量来自你的 A 站，从而更好地保护 A 站侧的分享隐私。该选项用于加密跳转。

### 9. 什么是「留言」？

很多时候，分享给客户一个链接时，往往还需要一并告知对方一些信息，比如注意事项、使用说明、密码等，就可以用留言功能来说明。

客户打开短链并完成校验后，会先看到留言，再跳转到具体网址。

### 10. 什么是「有效期」？

可为短链设置到期时间；到期后链接自动失效，无法再打开真实目标。

适合限时分享、活动链接，或希望过期后无需手动删除的场景。也可与阅后即焚等选项一起使用。

### 11. 普通跳转和加密跳转有什么区别？

- **普通跳转**：环境检查通过后，尽快跳转到目标网址，路径更短。
- **加密跳转**：先进入验证页完成校验，再出站；真实目标不出现在首屏，并可配合密码、留言、无来源等能力，提高被简单爬取或预览的难度。

更在意打开速度，可选普通跳转；更在意目标地址不要轻易暴露，可选加密跳转。
